# VerityMesh Trust Lab

**Open Research. Verifiable Security. Digital Trust.**

We investigate practical security problems, evaluate existing approaches, and build accessible, explainable open-source tools informed by reproducible evidence.

Our mission is to make trust and security questions easier for developers and teams to **understand, test, and act upon**—without promising certainty that the evidence cannot support.

### Current focus: API security research

**API Trust Lens** is our first research direction: explore how developers can distinguish documented API protections from unverified authorization assumptions and behavior established through authorized testing.

### Future research directions

**TrueTrace:** Content provenance and media-authenticity evidence, with transparent uncertainty.

**AgentScope:** AI-agent permissions, tool boundaries, and least-privilege analysis.

### How we work

**Problem first · Primary sources · Reproducible tests · Limitations stated · Responsible disclosure**

The initiative is in an early research stage. No product is certified, and proposed approaches are not yet independently validated. We aim to publish our methods and results openly and welcome constructive technical review.

Interested in collaborating? Start with the [research library](https://github.com/VerityMesh-Trust-Lab/research/blob/main/research/README.md) and the questions raised in Brief 001. Please avoid posting private data or sensitive unpatched vulnerability information in public issues.

*Open research, practical engineering, and evidence before claims.*
